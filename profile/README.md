> **Nossa Missão:** Nascemos como um projeto de extensão universitária do curso de Análise e Desenvolvimento de Sistemas da **UNIFOR**. Nosso grande objetivo é realizar o mapeamento colaborativo de inundações urbanas na cidade de Fortaleza e garantir que esses dados vitais cheguem de forma acessível tanto à população quanto aos órgãos públicos.

---

## 🌊 O Problema e a Solução

Cidades em rápido crescimento frequentemente sofrem com a falta de infraestrutura de drenagem. Em Fortaleza, os alagamentos causam perdas financeiras, transtornos de mobilidade e riscos à saúde pública. 

O **De Olho no Bueiro** entra como uma solução tecnológica e cívica:
1. **Mapeamento Colaborativo:** Permitimos que a própria comunidade relate problemas em bueiros e pontos de alagamento.
2. **Dados Acessíveis:** Transformamos dados hidrológicos complexos em informações claras e visuais.
3. **Ponte com o Poder Público:** Estruturamos os relatos para que possam ser utilizados por órgãos competentes na tomada de decisão e manutenção preventiva.

Nossa organização no GitHub existe para **validar essa solução tecnológica no mundo real**, servir como uma vitrine viva das nossas competências como desenvolvedores e, acima de tudo, **fomentar uma comunidade open source vibrante e colaborativa**.

## 🛠️ O Que Utilizamos (Nossa Stack)

Para garantir que nossa plataforma seja rápida, escalável e agradável para quem desenvolve (Developer Experience), optamos por um ecossistema moderno:

- **Frontend Web & Mobile:** ⚛️ React, ⬛ Next.js, 📘 TypeScript e 🎨 Tailwind CSS.
- **Backend (API):** 🐈 NestJS (Node.js) suportando nossa arquitetura de microsserviços/API REST.
- **Database:** Postgresql & Prisma ORM.

## 🤝 Como Contribuir

Nós **amamos** o movimento Open Source e queremos construir essa plataforma junto com a comunidade! Seja você um Dev Sênior, alguém dando os primeiros passos (Hello World!) ou um entusiasta de dados abertos, a porta está aberta.

### Seus Primeiros Passos:
1. **Explore as Issues:** Dê uma olhada na aba de `Issues` dos nossos repositórios. Procure pelas labels `good first issue` 🌱 ou `help wanted` 🤝 — elas são perfeitas para sua primeira contribuição.
2. **Faça um Fork:** Crie uma cópia do repositório para a sua conta e crie uma branch para trabalhar (`git checkout -b feat/minha-nova-feature`).
3. **Mão na Massa:** Escreva seu código, teste e não esqueça de documentar!
4. **Abra um Pull Request (PR):** Descreva de forma clara o que você fez. Nosso time fará um review amigável e construtivo.

> **Dica DX:** Recomendamos dar uma olhada no arquivo `CONTRIBUTING.md` dentro de cada repositório. Lá explicamos nossos padrões de commits, linters e formatação para que sua PR seja aprovada mais rápido!

## 👥 Quem Somos

O **De Olho no Bueiro** é mantido ativamente por uma equipe multidisciplinar de **7 pessoas**, unida pela vontade de aplicar a tecnologia em benefício da sociedade civil. Essa iniciativa nasceu e respira dentro das instalações da Universidade de Fortaleza (UNIFOR).

Nosso time foi estruturado para cobrir o ciclo completo de um produto digital:
- 👩‍🏫 **Coordenadora do Projeto**
- 🎯 **Líder de Projeto / Tech Lead**
- 💻 **Desenvolvedor Web**
- ⚙️ **Desenvolvedor Backend**
- 📱 **Desenvolvedor Mobile**
- 🚀 **DevOps / Infraestrutura**
- 📢 **Marketing e Comunicação**

Sinta-se à vontade para se juntar à nossa comunidade. Juntos, vamos manter o **De Olho no Bueiro**! 👁️💧
